Swarangan — Setup Guide

Switches on the admin panel, the database and the keepalive. About 30 minutes, once. Every service is free — no card needed.

0 of 10 steps done
The public website already works without any of this. These steps only turn on the admin panel. Do them in order, and do step 3 before sharing the site's link anywhere.
1

Create the Supabase project

  1. Sign up at supabase.com and click New project.
  2. Region: Southeast Asia (Singapore).
  3. Database password: click Generate, then save it in a password manager. It cannot be recovered.
  4. Wait a minute or two for it to finish.
2

Create the database

  1. In Supabase, open SQL Editor → New query.
  2. Open this file from the project folder, copy all of it, and paste it in:
    supabase/migrations/20260913000001_init.sql
  3. Click Run. You should see "Success. No rows returned".
3

Turn off public sign-ups

Do not skip this. Otherwise anyone who finds the database address could create an account.
  1. Authentication → Sign In / Providers.
  2. Switch off "Allow new users to sign up". Save.
4

Create the admin account

  1. Authentication → Users → Add user → Create new user.
  2. Enter the admin's email and a strong password. Tick Auto Confirm User. Create.
  3. In the users list, copy that user's UID.
  4. Go back to SQL Editor, paste this, replace the placeholder with the UID, and Run: 
insert into public.admins (user_id) values ('PASTE-THE-UID-HERE');

Only people added this way can sign in to the admin panel — even with the right password. Repeat for anyone else who needs access.

5

Collect the keys

In Supabase: Project Settings → API Keys.

Copy this It is called
Project URL NEXT_PUBLIC_SUPABASE_URL
Publishable key (starts sb_publishable_) NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
Secret key (starts sb_secret_) SUPABASE_SECRET_KEY
The secret key unlocks everything in the database. Never email it, paste it into a chat, or share a screenshot of it.

You also need two random secrets. In a terminal in the project folder, run this twice and keep both results: 

node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

The first is AUTH_THROTTLE_PEPPER, the second is CRON_SECRET.

6

Try it on your computer

  1. In the project folder, copy .env.example and name the copy .env.local.
  2. Fill in the five values from step 5.
  3. Run:
npm run dev

Open localhost:3000/admin and sign in with the admin account.

7

Check the security rules

This tries to break into the database the way a stranger could, and reports anything it gets through: 

npm run verify:rls

Every line must say PASS. If any says FAIL, stop and don't publish until it's fixed.

8

Put it live on Vercel

  1. In the Vercel project: Settings → Environment Variables.
  2. Add the five values from step 5, plus NEXT_PUBLIC_SITE_URL = https://www.swarangan.sg. Choose Production.
  3. Go to Deployments and redeploy the latest one.

The daily database ping starts on its own after this.

9

Add the backup ping on GitHub

The free database pauses after about a week with no activity, and waking it is a manual click. Visiting the website does not count. Two separate daily pings stop this from happening.

  1. In the GitHub repository: Settings → Secrets and variables → Actions → New repository secret.
  2. Add SITE_URL = https://www.swarangan.sg
  3. Add CRON_SECRET = the same value you gave Vercel.
  4. Actions → Supabase keepalive → Run workflow to test it now.

The admin dashboard shows when the last ping arrived and warns if one is missed.

10

Get found in Singapore

The website already describes the school to Google and to AI assistants. No code can guarantee a top position — for a local school these steps matter most:

  1. Google Business Profile — the biggest factor for Maps and "near me" searches. At google.com/business, add Swarangan as a music school with exactly the same name, address and phone as the website. Ask happy parents for Google reviews.
  2. Google Search Console — at search.google.com/search-console, add the site and submit https://www.swarangan.sg/sitemap.xml.
  3. Bing Webmaster Tools — at bing.com/webmasters, import from Search Console. ChatGPT and Copilot use Bing's index.
Use the address exactly as the website shows it: 52 West Coast Crescent, #07-09 West Bay Condominium, Singapore 128036.
If something goes wrong
You see What to do
"The admin panel has not been set up yet" One of the five values is missing. Re-check step 5 and step 6 (or step 8 on Vercel).
"Too many attempts" The break-in protection switched on. Wait — it unlocks by itself (1 minute at first, never more than 15). A successful sign-in resets it.
Right password but "Invalid email or password" That account isn't on the admin list. Re-do step 4.
The database was paused anyway Supabase → the project → Restore. Then check the keepalive box on the admin dashboard to see which ping stopped.
